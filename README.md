# ci-triage-demo

A tiny checkout library with a real test suite, used to show the
[CI Triage Agent](https://github.com/yosrkharrat/CI-triage-agent) GitHub Action
diagnosing a failed run on a pull request.

The whole install is [one workflow file](.github/workflows/ci-triage.yml) and a
`GROQ_API_KEY` secret.
